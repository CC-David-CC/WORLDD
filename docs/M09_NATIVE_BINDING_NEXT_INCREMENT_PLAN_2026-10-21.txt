CURRENT SOURCE MAP: WHAT EXISTS

Native X server, at the planning base:

- server/xlibre/spatialinput.c: `open_seat()` creates the compositor-owned native seat and four devices; `cancel()` releases tracked input and clears native context; `bind_application()` sets the application controller and device association; `operate()` handles existing v1 input requests; `dispatch()` unpacks and replies; `SpatialInputExtensionInit()` and `reset()` own extension lifecycle.
- server/xlibre/spatialinput.h exposes only `SpatialInputExtensionInit`, `SpatialInputAuthorizeClient`, and `SpatialInputRoute`. It has no observer arm, descriptor bootstrap, native epoch query, or output writer.

- server/xlibre/meson.build generates existing input/security protobuf-c code and links spatialinput.c. The v2 observer schema, serializer, transport, and default-off registration are absent at this planning base.

Prepared, private native helpers, in their separate source pins:

- `spatialinputobserver_lifetime.h`: `SpatialObserverLifetimeInit/Reset/Session`, `SpatialObserverPinDevices`, `SpatialObserverSnapshotDevices`, `SpatialObserverPinClient/ClientMatches`, `SpatialObserverPinWindow/WindowMatches`, `SpatialObserverPinNativeClient`, and `SpatialObserverSnapshotContextV2`. They return process-local epoch/value pins. They retain no DIX pointer in wire data.
- `SpatialObserverNativeClientRole` values are INVALID=0, APPLICATION=1, SUPERVISOR=2, COMPOSITOR=3. The wire role values differ. Map explicitly: APPLICATION 1 to wire APPLICATION 4; SUPERVISOR 2 to wire SUPERVISOR 1; COMPOSITOR 3 to wire COMPOSITOR 3. Reject INVALID and unknown values. Never cast these enums.
- `spatialinputobserver_capture.h/.c`: `SpatialObserverCaptureArm/Read/Reset` captures v1 arm and one callback event. It does not sample the ordered cancel/bind transitions required by v2.
- `spatialinputobserver_serialize.h/.c`: `SpatialObserverSerialize` emits v1 Arm and ObserverPress records only. The independent probe supplies its own ProbeReceiptBatch. It is not the v2 transition serializer.

World/compositor path, at the planning base:

- src/world/actors.hpp/.cpp: `Actors::Actor` stores actor entity, optional authenticated `ActorRef`, application-control lease, and native input state. `authorize_input()` checks observation/control authority and acquires the broker lease. `release_input()` cancels input before release. `send_input()` rechecks control. `route_input()` turns authorized actor actions into renderer commands.
