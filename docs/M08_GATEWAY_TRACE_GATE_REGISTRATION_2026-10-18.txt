# M08 gateway trace test registration

Contract: CTest registers `actor-cabinet-gateway-instrumentation` as a direct,
30-second Python control. Its import path includes generated build Python
bindings, the handoff source root, and `tests/core`. The fixture build target
exposes both Python sources and depends on `broker-python-protobuf` and
`grants-python-protobuf`. The M08 local inventory gate requires this exact
CTest name. A configured profile that lacks the registration must refuse
before launching the inherited gate.

This is an additive registration. It does not replace or edit the locked
`workspace-actor-cabinet-gateway` acceptance test. It does not add a delegated
runtime, native display, or input wrapper to the pure transcript controls.
The target-specific fixture build target is available to create the generated
Python imports before running the direct test. CTest inventory inspection does
not execute test commands.

## Selected checks

- Run `tests/harness/test_m08_deployed_gate.py` with Python `-B`. This checks
  mandatory-name refusal, both-profile validation, direct invocation, import
  paths, timeout, fixture sources, and generated binding dependencies.
- Configure Debug and ASan/UBSan with `BUILD_TESTING=ON` and
  `SPATIAL_INPUT_TESTS=ON`; inspect each actual CTest inventory with
  `ctest --show-only=json-v1`. Compare names against the reviewed integration
  inventories and pass candidate rows through `require_inventory`.
- Build only `actor-cabinet-gateway-instrumentation-fixture` to generate the
  required Python protobuf imports. Run the 14-method gateway transcript
  control directly. This target closure generates Python bindings only; no
  project C++ runtime or CTest is run on middle-child.
