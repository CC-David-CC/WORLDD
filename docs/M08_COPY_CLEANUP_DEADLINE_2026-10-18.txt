Recursive descendant pruning checks the same deadline. No cleanup step starts a fresh per-job budget.

SQLite virtual-machine work uses a progress handler. Statement row steps, transaction writes, commits, queued operations, and close paths check the same deadline. Ordinary journal construction keeps its previous behavior. Pin verification accepts an operation deadline without storing it in the reusable pin.

Expiry rejects the stopped receipt. The exact process-scope tree, copy stage, and durable partial journal outcomes remain available for exact retry. The drain callback commits proof before the worker cgroup is unlinked. A terminal uncertainty remains immutable. Synchronous filesystem and kernel calls cannot be interrupted; the code checks the deadline before and after them and rejects a late completion receipt.
