## Vector provenance and limits

Canonical-byte vectors are manually specified literal UTF-8 expectations. Their hex is
stored, not regenerated by the implementation under test during the test run. The framed
object vector is a fixed literal serialized envelope with a SHA-256 expectation. A raw
SHA-256 `abc` known-answer value and the RFC Ed25519 vector provide independent primitive
checks. Cross-Python-process reproducibility is tested; a second-language codec is not yet
implemented and remains a mandatory future acceptance task.

The dependency pin records the tested environment, not a claim of latest-version security.
P01 must review the actual target dependency artifacts/advisories and make a hashed offline
lock set. Do not extrapolate verification of one Python/OpenSSL build to every platform.
