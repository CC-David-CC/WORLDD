Native application launch: 2026-10-08

The production broker now accepts a sealed native configuration descriptor.
It gives each confined application a distinct native credential and a pinned X socket.
The application receives no broker channel or supervisor credential.

Confirmed lifecycle defect found during review

The first implementation revoked native access only when someone requested process.wait.
An exited application could retain a usable native credential while the broker was idle.
The expanded test suite reproduced this failure on sb16 and sb16-2.
The broker now reaps completed processes during its normal event loop.
Recorded exit status remains available after native access is revoked.

A second review found actor-authority cancellation could disconnect the shared native issuer.
That disconnected unrelated applications and revoked their credentials.
Both hosts reproduced failures before and during issuance.
Authority checks now surround the bounded native request.
A later denial revokes only the tentative credential.
Both regression checks passed with the corrected production client on both hosts.
