Defect: Mesa 25.2.8 GLVND vendor does not register its default EGL cleanup.
Status: A project-local candidate passes a controlled startup/shutdown comparison on sb16.
Qualification remains incomplete. System graphics libraries remain unchanged.

The native XLibre sanitizer run leaks 3176 bytes in five allocations on both hosts.
Loaded-module diagnostics resolve the allocations to Mesa EGL display and device records.
The device records also own allocations from libdrm.

Mesa defines default cleanup functions for its global display and device lists.
The release source registers exit cleanup only when _eglAddAtExitCall receives a function.
No remaining EGL source caller registers that handler.
The candidate permits registration without adding another cleanup function.
It calls that registration during GLVND vendor initialization.
