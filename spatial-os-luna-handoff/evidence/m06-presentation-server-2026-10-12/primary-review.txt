M06 compositor presentation service: focused increment review

Production changes
spatialwm has an authenticated private presentation mode.
The control owner must launch the compositor. A retained pidfd pins its lifetime.
Control requests attach, select, inspect, and retire world channels.
Each world channel has a fixed binding and retained process handle.
World channels initialize their own sealed native input configuration.
Reservation order does not constrain initialization order.
Only the selected world can draw the foreground. Selection clears old pixels.
World transport failure stops routing and attempts native input retirement.
Unconfirmed native cleanup remains UNCERTAIN. It cannot acknowledge clean shutdown.
The legacy compositor entry point remains available for existing callers.

Review
Reviewed all ten changed production/build/test files listed in source-sha256.json.
Checked descriptor ownership, exception cleanup, generation identity, sender credentials,
process lifetime, request correlation, pixel selection, and native seat retirement.
The control owner pin closes the reviewed PID-reuse/lifetime gap.
No locked acceptance files changed. This adds a private production protocol.
World channel identifiers do not replace actor authorization in worldd.
