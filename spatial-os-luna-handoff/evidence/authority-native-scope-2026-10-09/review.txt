Production boundary

NativeScope owns one BROKER or COMPOSITOR credential through its own supervisor connection.
It reads private configuration from a bounded, fully sealed inherited memfd.
It checks role, field presence, identity lengths, display range, and unknown protobuf fields before issuing a grant.
The supervisor cookie is never returned to the launched authority.
The returned grant belongs to the retained native connection and names its server and launch identity.

The existing NativeLaunch transport now has a private parameterized connection initializer.
The broker constructor still requires BROKER. The supervisor constructor requires SUPERVISOR.
Both paths retain pathname pinning, peer PID and UID checks, native server identity checks, and sequence validation.
Existing application issuance, checkpoint callbacks, revocation, and channel-failure behavior remain unchanged.
The initializer is private. Ordinary actor requests do not select its expected role.

Stop sends the retained credential ID to the retained server connection.
Only OK with revoked=true records successful cleanup.
Unknown credentials, socket loss, timeout, and malformed replies cannot produce a stopped receipt.
The native server drains credential descendants and client cleanup callbacks before its reply.
An exact local retry after confirmed cleanup returns the retained public identity without another server operation.
The destructor attempts checked cleanup. Uncertainty terminates unsuccessfully instead of returning success.
