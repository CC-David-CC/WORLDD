====================

fixture enrolls B and C through separate issuer keypairs. Three authenticated
`SessionPeer` channels represent A, B, and C. A independently delegates workspace
access, observation, and control rights to B and C. Only B's application control
and observation grants are revoked. A and C roots remain valid.

The witness captures B's empty world before launch, then protected pixels after
delegation. B holds button 1, Shift_L, and `a`. The test records both held keycodes.
C receives typed BUSY while B owns the lease. After revocation, the test immediately
requests C control without an XSync or an intervening wait for releases. C presses
unique key `c` and button 1 on the same application. The full probe stream, sliced
at the acknowledged XSync baseline from before B's holds, must show B's button and
both key releases before C's first fresh native button-1 press. Only then does the
witness check B's empty pixels, absent surface metadata, typed FORBIDDEN control,
and A's continuing protected view.

The test pins the actual launched app process, worldd, spatialwm child, and X
server by PID, `/proc` start ticks, executable SHA-256, and liveness through
`geometry_process_identity.collect`. The native probe is found only by exact argv.
Its direct parent must contain the launched probe command, share its PID namespace
and cgroup, and descend from the known workspace broker PID. The compositor is
found among worldd's direct children and must resolve to the fixture's actual
`spatialwm` executable. This is not global process-name or arbitrary-Python
search.

Cleanup releases C's held inputs, requests probe shutdown, waits for the managed
application, and asserts exit code zero.

Cleanup preserves every returned error in its aggregate failure diagnostic.
State inspection must return a state result. Stop is attempted even if inspection
