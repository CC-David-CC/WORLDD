3. Workspace and execution authority
tests/core/test_workspace_authority.py checks actual confined processes and project-file effects.
Credential or access revocation can preserve independently authorized execution.
Actor or required execution revocation must stop the affected process tree.

The surviving-process cases require the process to write its completion file after revocation.
The termination cases check real process disappearance and absent completion effects.

4. Observation and application control
The application-access, application-observation, application-control-lease, and world-application-control suites cover separate decisions.
tests/core/test_world_application_control.py checks actual application events and native input release.
Observation alone does not permit control. Read-only authority cannot control a writable application.
Control revocation releases input while the independently authorized application stays mapped and observable.
Observation revocation removes pixels and cancels control. Independent control grants remain usable.
These checks use the dedicated software display. They do not certify physical devices or GPU performance.
