The live sb16 Debug core log records `AttributeError: NativeBroker has no attribute closed` in CTest #150 `workspace-participant-native` and #151 `workspace-participant-settlement`. The custom NativeBroker constructor follows `LeaseBroker` into `test_application_access.Broker.__init__`, which does not initialize the base BrokerProcess close-state fields. Its resource-wrapper close path delegates to `test_workspace_authority.BrokerProcess.close`, which expects the complete lifecycle state initialized by `initialize_broker_lifecycle`.

The fixture now invokes that shared initializer before starting LeaseBroker setup. If setup raises, it uses the base close path and preserves the original exception while attaching any cleanup failure. The regression injects an initialization failure after allocating the stream and log, then checks complete cleanup and repeated close safety.

CTest #154 `application-observation` is a separate failure. `test_application_scope_filters_other_live_application` launches a second process and receives `RESOURCE_EXHAUSTED: Workspace or actor resource capacity is reserved`. This does not match the NativeBroker close traceback and is outside this fixture repair. Other runtime errors remain separate until diagnosed.
