Implemented boundary
--------------------
The real XLibre server accepts a private inherited -spatial-observer-fd only in an enabled qualification build.
Default builds recognize the option and refuse it explicitly.
The endpoint must be a connected Unix seqpacket socket created by the direct launching parent.
The server checks peer PID, UID, and GID. Each packet must carry matching kernel sender credentials.
The server marks its descriptor CLOEXEC and nonblocking.
Malformed, oversized, noncanonical, unknown-field, ancillary-rights, and unauthorized-sender packets close the endpoint.
Received unexpected descriptors are closed. Ordinary X clients receive no observer API.
A ten-second monotonic startup budget closes an unused endpoint.
The hello reports a fresh 16-byte session nonce, native session epoch, and actual server process identity.
One setup request resolves real seats, native device roles, immutable application identity, target generation,
application window owner, compositor seat owner, and a separate privileged probe marker owner.
Supplied object epochs are never accepted as native truth. Setup does not acquire application control.
