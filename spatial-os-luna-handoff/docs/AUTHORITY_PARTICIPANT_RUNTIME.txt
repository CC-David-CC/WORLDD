Continue polling contiguous events while the authority synchronizes.

A concurrent revocation can reject activation with REVISION_CONFLICT.
Publish that rejection and new feed events. Require a new explicit synchronized activation request.
Never automatically retry an uncertain mutation.
Publish activated only after the issuer confirms the durable generation.
Keep feed and mutation traffic on that original service connection.
Bound idle feed waits so queued acknowledgements and stop requests make progress.
Do not advance applied state merely because a feed batch advertises a newer head.

Queue contract clarification
The command queue holds at most 128 outstanding commands, including unread command results.
Request IDs must be unique among outstanding commands. Zero is a valid request ID.
Consume all previous command results before submitting release.
A release request rejects subsequent submissions to prevent silently stranded commands.
The update queue holds at most 256 updates.
Receiving a feed update advances only the consumer-delivered cursor. It does not acknowledge cancellation.
The worker rejects skipped, future, and wrong-generation acknowledgements before sending them.
The consumer remains responsible for proving effects have settled before submission.
