Configure a private journal directory and delegated cgroup directory.
Supply the exact supervised launch binding, participant attachment, and supervisor authorization.
Supply the authority executable and arguments through AuthorityProcessLaunch.
Supply an absolute child participant configuration path and reserved participant descriptor.
Provide inherited source descriptors in the same order as launch.inherited_fds.
Keep configuration files private. Do not commit credentials or runtime configuration.

The command accepts the configuration path, sealed native-scope descriptor, and private management descriptor.
The native configuration remains a sealed inherited file.
Validate management peer credentials against the direct parent and effective UID.
Never pass the management descriptor, native supervisor input, or supervisor secrets to the child.
Reject descriptor aliases of native input and management input.
Preserve the existing ProcessScope descriptor checks and startup gate.

Startup

Prepare the private child channel.

Event loop

Pump the participant relay automatically.
Use the existing bounded private framed transport for management.
Management messages reuse AuthorityLaunchRequest and AuthorityLaunchReply.
Permit only inspect and stop operations.

Preserve request correlation.
