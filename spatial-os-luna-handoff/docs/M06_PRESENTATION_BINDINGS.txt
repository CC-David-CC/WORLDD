Proposed ownership and transport
Give the host session the retained compositor process and its graphics credential scope.
Give each world a separate inherited rendering channel attached through the session's private control channel.
The compositor associates that channel with the full binding; a world cannot select another channel's identity.
Keep scoped native input credentials under the existing world supervisor and its cleanup receipts.
Transfer sealed configurations only through an authenticated private descriptor handoff.
Use versioned protobuf control messages. Validate descriptor count, seals, peer identity, message identity, and bounds.
Keep all world channels nonblocking with independent fixed partial-frame deadlines and bounded queues.
One incomplete frame or dead world must not block other worlds or terminate graphics.
Keep foreground presentation selection separate from background actor observation.
Retired channels and stale generations must be rejected before render or input effects.
Resolve socketpair creator credentials versus sender credentials explicitly when implementing peer checks.
Do not assume SO_PEERCRED on an inherited socketpair reports the executing child.

Failure handling to implement
Normal detach requires confirmed input retirement and actor-context checkpointing before destination input activates.
World-channel loss disables that binding immediately and reports cleanup uncertainty.
A revoked native connection can prevent local retirement acknowledgment even after server cleanup succeeds.
Use the exact supervisor cleanup receipt to resolve that state; do not convert the transport exception into success.
Keep the existing normal compositor mode until the new production session path is wired and qualified.
These are implementation constraints, not completed features or qualification evidence.
