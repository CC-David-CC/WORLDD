Contract additions
The trusted presentation owner registers geometry-only targets through its private channel.
Each target binds world, actor, view session, authority incarnation, authority generation,
and a globally allocated local presentation generation. It has no native input identity.
Registration, selection, publication, and retirement receive checked compositor replies.
Attempted registration ownership is recorded before IPC. Unknown acknowledgements retain it.
Only checked no-effect registration errors remove attempted ownership.
Failed retirement retains target ownership and reports unavailable control.
Shutdown requires confirmed retirement of every geometry target and local world channel.

The compositor rejects wrong context, stale sequence, unknown fields, and descriptors
before drawing geometry. Local duplicate attachment still returns IN_USE.
Geometry frames contain no application surfaces, XIDs, captures, or input instructions.
Renderer::draw_geometry constructs the same RenderScene drawing representation.
It never converts a remote authority into a local world channel.

HostSessionConfig adds remote_worlds with trusted actor TLS profile paths.
The existing authenticated actor client supplies foreground frames after activation.
The loop permits one bounded in-flight exchange and stores no obsolete frame queue.
It drains queued control requests before polling geometry after a 100 ms quiet interval.
Checked observation denial retires presentation while preserving unrelated actor authority.
Transport failure retains the client's existing no-replay fence.
World transitions do not restart the local XLibre server or spatialwm.

HostControl adds geometry_status as a read-only current-generation operation.
It reports only the last compositor-acknowledged frame sequence, revision, camera,
world, actor, room, and presentation/authority generations.
It contains no geometry, application metadata, session credentials, or provider secrets.
Denied, retired, unavailable, and failed presentations return redacted unavailable status.
Stale generation rejects before any status disclosure.
Actor activation, host selection, and displayed-frame acknowledgement remain separate facts.
