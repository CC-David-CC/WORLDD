## Contract

The authenticated actor channel exports current-room geometry after WORLD_OBSERVE checks.
An activated open reply binds a 32-byte view ID, authority service incarnation, and
activated authority generation. Prepared replies do not bind an active view. The actor
does not supply any of these values. The client checks them before releasing its first
and every later view. A malformed view permanently fences the client.

The view includes the camera, room, durable world revision, drawable panels, barriers,
portals, objects, and other actor markers. It excludes labels, portal destinations,
workspace metadata, application identities, native surfaces, pixels, XIDs, input,
and descriptors. Live actor poses can change without a durable revision increment.

The server tracks queued geometry observation separately from application observation.
It cancels queued geometry when observation authority is revoked. It checks the entire
reply envelope against the 1 MiB protocol frame limit before writing. The geometry
validator checks required fields, kind/category, shapes, field combinations, stable
unique IDs, aggregate entity count, render configuration, and encoded size. Generic
`validate_message` already checks unknown fields, invalid enums, and nonfinite doubles.

## Focused registered cases

- `actor-geometry-client-hostile-peer`: a fixture protocol peer sends valid and hostile
  replies to the production client. Cases cover first and later context, stale sequence,
  malformed geometry, unknown fields, count boundary, oversized and truncated frames.
- `actor-geometry-world-headless`: real issuer enrollment, participant registration,
  authority grants, local and TLS actor channels, prepared activation, revocation,
  departure, credential revocation, room privacy, second actor motion,
  blocked output cancellation, count limits, oversized snapshot rejection, and an unrelated actor.
- `world-authority`: its existing native application-boundary case now requests geometry
  between two application observations. It verifies geometry has no application output.
  Its native object-scope case also edits through authenticated owner grab, move, and
  commit actions. Geometry reflects the resulting pose and durable world revision.

The queued-output case uses a small receive buffer and a valid response larger than
the socket buffer. It checks that revocation leaves no completed view frame.
The high-count cases create thousands of real objects. Their timeout is 600 seconds.
