Date: 2026-10-21
Status: source checkpoint only; UNQUALIFIED

A fresh control acquire during an execution durability loan uses the existing
cached WorkspaceAuthority requester classifier. A revoked requester receives
UNAUTHORIZED. An unavailable authority receives UNAVAILABLE. An active
requester still receives BUSY. Missing principal or missing authority retains
the existing BUSY result.

The classifier reads cached state only. This path does not enter the SQLite
handler or issue an issuer request while the execution connection is lent.
Protocol validation and managed native-server ownership checks still precede
the classification. Control release remains available during the loan.

The broker regression uses the real ResourceBroker fixture and the
SPATIAL_TEST_REVOCATION_COMMIT_GATE fault, enabled only with --fixture-faults.
It revokes a real actor, waits for the actual commit worker to enter the gate,
then checks revoked and independent active control acquires. It also checks
that the revoked controller can acknowledge release while the gate remains
held. The primary process identity is checked after revocation, during the
held loan, and after release. A second selected method stops the real issuer daemons while the commit
gate remains held and checks the active requester's unavailable result.

The existing issuer-exit assertion and its accepted UNAVAILABLE or
UNAUTHORIZED codes remain unchanged. No lock, schema, or acceptance contract
changed.
