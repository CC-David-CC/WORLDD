Existing production boundary
Actor process requests reach workspaced through the private protobuf broker.
Workspace policy, actor authority, and the requested profile determine effective access.
The broker uses ApplicationProcess in src/workspace/process.cpp for application execution.
Native applications add only their provisioned display socket and application credential.
The native path uses the same application process boundary.

ApplicationProcess configures separate namespaces through the project Bubblewrap entry point.
It pins project, repository, and state directories before mounting them.
System dependencies and the namespace root are read-only.
Project and Git mounts follow effective write authority.
The application has its own writable state and temporary directories.
The environment is explicit. Host SSH agents, desktop buses, and provider credentials are absent.
The process setup closes unselected descriptors and drops capabilities.
The application initializer checks no_new_privs before execution.
The seccomp filter rejects namespace creation, mount changes, process-memory inspection, and selected kernel administration operations.
The startup pipe holds the namespace until the broker pins its leader.
Process stop uses retained pidfds and confirms namespace exit.
